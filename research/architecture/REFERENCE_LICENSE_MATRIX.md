# Матрица аудита лицензий 20 референсных проектов (License Audit Matrix)

**Дата:** 2026-09-16  
**Статус:** ОБЯЗАТЕЛЬНЫЙ АУДИТ ДО ПЕРЕНОСА ЛЮБОГО КОДА  
**Главное правило архитектора:**  
Если лицензия несовместима, имеет сильный копилефт (GPL/AGPL) или коммерческие/SaaS ограничения (BSL, Fair-code, Sustainable Use) — **КОД НЕ КОПИРУЕТСЯ**.  
Разрешается изучать и заимствовать:
- архитектурные паттерны и слои;
- контракты и схемы API;
- концептуальные модели предметной области (DDD);
- подходы к жизненным циклам и конечным автоматам (State Machine);
- концепции UX и эргономики рабочих мест.

Никакого прямого копирования (copy-paste) чужого исходного кода в KORKEM не допускается.

## 2. Юридические выводы и директивы для KORKEM

1. **Группа AGPL-3.0 (Twenty, Cal.com, NocoDB, Plane):**
   - **Юридический риск:** Раздел 13 лицензии AGPL-3.0 постановляет, что предоставление доступа к модифицированной программе через сеть (Network Interaction / SaaS / Web API) приравнивается к распространению и обязывает предоставить полный исходный код всего производного продукта под той же лицензией AGPL.
   - **Директива:** **Полный запрет на перенос кода.** Из этих репозиториев заимствуются исключительно архитектурные идеи:
     - Из *Twenty*: метаданные кастомных полей, активность таймлайна (Activity Timeline), фильтрация представлений;
     - Из *Cal.com*: алгоритм расчета доступных окон замерщика/монтажника (Slot Availability Engine);
     - Из *Plane*: модель жизненного цикла сменных задач (Cycle / Module / Issue State Machine);
     - Из *NocoDB*: табличный грид и фильтры.

2. **Группа Fair-Code / BSL / Source-Available (n8n, Directus, Novu, Medusa):**
   - **Юридический риск:** Лицензии BSL 1.1 и Sustainable Use запрещают использование кода для создания конкурирующих коммерческих платформ или предоставления сервиса третьим лицам без покупки коммерческой лицензии у вендора.
   - **Директива:** **Полный запрет на перенос кода.** Извлекаются концепты:
     - Из *n8n*: канонический цикл «Триггер -> Условие -> Действие», структура полезной нагрузки событий;
     - Из *Directus*: изоляция схем данных, декларативные хуки мутаций;
     - Из *Novu*: шаблон многоканальных уведомлений (Push, SMS, WhatsApp, Telegram) с дайджестом и дедупликацией;
     - Из *Medusa*: компенсационные шаги при отмене составных операций (Workflow Compensation / Sagas).

3. **Группа Permissive Open Source (Temporal, Trigger.dev, Supabase, ElectricSQL, Browser Use, OpenAI Agents SDK, Langfuse Core):**
   - **Юридический статус:** Лицензии MIT и Apache 2.0 допускают коммерческое использование, модификацию и интеграцию в проприетарные продукты с сохранением копирайта и текста лицензии.
   - **Директива:** Код может служить прямым ориентиром для прототипирования, однако для KORKEM предпочтительна собственная компактная реализация на чистом Python / Frappe без раздувания зависимостей:
     - Из *Temporal* и *Trigger.dev*: алгоритм идемпотентного выполнения шагов с экспоненциальным бэкапом и очередью недоставленных сообщений (Dead-Letter);
     - Из *OpenAI Agents SDK*: строгие схемы JSON Schema (`strict_schema`), контракты функций и барьеры безопасности (Guardrails);
     - Из *Langfuse*: структура метаданных телеметрии AI (`trace_id`, `observation_id`, `latency_ms`, `tokens_prompt`, `tokens_completion`, `cost_usd`).
