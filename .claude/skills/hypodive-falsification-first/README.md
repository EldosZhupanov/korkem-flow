# HYPODIVE Falsification-First Skill

Reusable red-team skill for scientific ML, benchmarks, papers, architecture,
AI systems and product claims where a polished story can hide a confounded result.

Recommended invocation:

```text
Use $hypodive-falsification-first. Audit the strongest claims in this repository
before making improvements. Start in Mode A. Escalate only if the central claim
survives. Compare against the strongest simple baseline under matched rules.
```

Start with [SKILL.md](SKILL.md). Modes: 30-minute triage, 2-hour focused audit,
and an explicitly scoped full red-team. Time ceilings are defaults, not targets.
References cover theory, experiments, novelty and engineering failure tests;
load only what the task requires. Templates preserve claims and evidence trails.

Works independently or on a frozen Builder handoff. A NO-GO with decisive evidence
is a successful outcome; missing evidence is not automatically a refuted claim.
For hosts without native skills, reference this folder's SKILL.md explicitly.
