## 10. How the vendored repos are mounted without modification

- `erpnext/` and `crm/`: bind-mounted read-write into the `bench` container at `/workspace/vendor/erpnext` and `/workspace/vendor/crm`. `bootstrap.sh` calls `bench get-app --soft-link /workspace/vendor/erpnext` (and same for `crm`) — confirmed (during planning, by reading `bench`'s own source) that `--soft-link` performs a filesystem symlink into `apps/erpnext`/`apps/crm` and **executes no git command whatsoever** against the source path — no clone, no checkout, no branch switch. The only writes that land inside these trees are `bench build`'s compiled-asset output (`public/dist`, `public/frontend`), and every one of those paths is already listed in each repo's own `.gitignore` — verified as the concrete pass/fail check in step 13 above.
