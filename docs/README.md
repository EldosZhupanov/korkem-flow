# docs

Справочная документация. **Источник правды — пять файлов в корне:**
`NOW.md`, `ROADMAP.md`, `PLAN.md`, `PROJECT.md`, `CLAUDE.md`.
Если файл отсюда им противоречит — правы они.

Правила ведения документации — скилл `.claude/skills/korkem-docs/`.

---

## `archive/` — история, не истина

**Не читать, чтобы узнать, как работает система.** Читать, только чтобы найти
причину конкретного решения — и убедившись по актуальным документам, что
решение ещё в силе. Каждый файл несёт баннер об этом.

| папка | что там |
|---|---|
| `phases/` | 29 отчётов по фазам 5–33 (авг. 2026). Каждый содержит раздел Limitations — поэтому им можно верить как истории. |
| `audits/` | ревизии и gap-анализы, вытесненные текущими `ROADMAP.md` и `PLAN.md`. Оценки в них устарели. |
| `sprint1/` | чек-листы Sprint 1: как поднимался стенд и во что упирались. Много практических деталей о Docker и bench. |
| `research/` | исследования архитектуры, deep scan вендорных репозиториев, прежний master execution prompt. |
