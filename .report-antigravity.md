# Отчёт: экран «Фурнитура»

## Результат

Экран «Фурнитура» реализован как отдельный read-only раздел рядом с каталогом
материалов. Клиент обращается к whitelisted GET-методу
`korkem_manufacturing.api.materials.hardware`; мутаций через `/api/resource`
нет. Компания не принимается от клиента и определяется серверным
`current_company()`.

Карточки различаются по назначению:

- петля показывает наложение, угол, чашку, систему присадки и доводчик;
- направляющая показывает длину и допустимую нагрузку;
- ручка показывает отдельное межцентровое расстояние крепёжных отверстий и
  цвет;
- опоры и полкодержатели используют нейтральную карточку с имеющимися
  размерами.

Тип наложения показан термином цеха и поясняющей строкой: фасад перекрывает
торец, два фасада делят торец или фасад находится внутри корпуса. Отдельную
схему сейчас не добавлял: для первого read-only среза текст передаёт правило
установки без нового графического языка и без риска нарисовать неверную
геометрию.

## Исправленные дефекты контракта

Во время повторной проверки исходной реализации найдены и исправлены четыре
ошибки:

1. Межцентровое ручки ошибочно читалось из длины направляющей. В DocType, API и
   Dart-модель добавлено отдельное nullable-поле `hole_spacing_mm`.
2. Неуказанная глубина чашки автоматически превращалась в 11,3 мм, а
   неуказанный доводчик — в `false`. Значение по умолчанию удалено, доводчик
   стал трёхсостоянием `unknown/yes/no`, а публичный контракт нормализует
   пустые числовые поля в `null`.
3. Flutter отправлял лишний параметр `offset`, отсутствующий в серверном
   контракте. Остался только `start`.
4. После выбора наложения и перехода к «Все типы» скрытый фильтр наложения
   сохранялся. Теперь при уходе с петель он очищается.

Для всех четырёх дефектов сначала были получены красные regression-тесты,
после минимальных исправлений — зелёные targeted и полные наборы.

## Изоляция и устойчивость

- сервер фильтрует `Furniture Hardware` по `current_company()` и `active=1`;
- сигнатура endpoint не содержит `company`;
- тест подтверждает, что запись другой компании не возвращается;
- страница ограничена `MAX_PAGE=100`, `total` считает всю отфильтрованную
  выборку;
- все необязательные поля остаются `null`, если факта нет в ERPNext;
- фильтры, поиск с debounce, пагинация и пустые состояния покрыты тестами;
- экран и все новые строки локализованы на русском, казахском и английском;
- иконки проходят через общий семантический словарь `AppIcons`.

## Ограничения

- Это только каталог и подбор: создание и редактирование фурнитуры в Flutter
  не реализованы.
- Складские остатки, цены и совместимость по толщине фасада не добавлялись:
  их нет в согласованном контракте этого среза.
- Отдельная графическая схема наложения отложена до проверки текстового
  объяснения на пилоте.
- Remote CI в рамках этой задачи не запускался.
- Коммит не создавался по условию задачи. В рабочем дереве присутствуют
  отдельные незакоммиченные изменения `korkem_ai`; они не относятся к экрану
  фурнитуры и не изменялись при этой работе.
