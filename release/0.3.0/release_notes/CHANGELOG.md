# KORKEM Flow — Журнал изменений (Release Notes)

## Версия 0.3.0 (Сборка 5) — 17 сентября 2026

### 🎯 Главные нововведения

1. **Сквозной производственный цикл (End-to-End Furniture Production Loop)**
   - Поддержка полного цикла мебельного заказа: от первого замера до монтажа и подписания акта приема-передачи.
   - Единая машина состояний заказа (`korkem_state`): Замер → Проект → Расчет → Договор → Предоплата → Резерв материалов → Раскрой → Кромкооблицовка → Присадка ЧПУ → ОТК → Доставка → Монтаж → Акт → Оплата → Гарантия.

2. **Деловые остатки листовых материалов (Sheet Offcuts)**
   - Автоматический учет и регистрация полезных обрезков ЛДСП и МДФ при раскрое.
   - Повторное использование остатков в новых заказах с приоритетом списания.

3. **Сдельная оплата труда (Piece-work Payroll)**
   - Автоматический расчет вознаграждения мастеров по закрытым операциям в Job Card.
   - Прозрачный учет выработки сотрудников цеха.

4. **Интеграция статусов и контроль оплат в клиентах**
   - В мобильном и десктопном приложениях отображаются актуальные производственные статусы заказов.
   - Индикаторы внесенной предоплаты (`advance_paid`) и остатка задолженности по каждому заказу.

5. **Мультиплатформенность и поддержка десктопа**
   - **Android**: Официальный APK-пакет и App Bundle (AAB) с поддержкой встроенных автоматических обновлений.
   - **Windows**: Портативный x64 архив (`.zip`), готовый к запуску без установки дополнительных компонентов.
   - **Linux**: Портативный x64 tar.gz архив.
   - **iOS / Web**: Поддержка PWA через браузер; нативный iOS Runner подготовлен к подписанию в Apple Developer Program.
